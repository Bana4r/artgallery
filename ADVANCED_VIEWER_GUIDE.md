# 📖 Guía del Visor Avanzado de Imágenes

## 🎯 **Características Principales**

### 🔍 **Zoom y Navegación**
- **Zoom con rueda del mouse**: Usa la rueda para acercar/alejar
- **Zoom táctil**: Pellizca con dos dedos en dispositivos móviles
- **Arrastrar imagen**: Cuando está ampliada, arrastra para navegar
- **Botones de zoom**: Controles + y - en la barra inferior
- **Zoom al 100%**: Presiona "0" para ver tamaño real

### 🖼️ **Modos de Visualización**
- **⊞ Ajustar**: La imagen se ajusta completamente a la pantalla
- **⊡ Llenar**: La imagen llena toda la pantalla (puede recortar)
- **↔ Ancho**: Ajusta al ancho de la pantalla
- **1:1 Actual**: Muestra la imagen en su tamaño original

### 🎨 **Controles de Imagen**
- **Brillo**: Deslizador para ajustar la luminosidad (50%-150%)
- **Contraste**: Deslizador para ajustar el contraste (50%-150%)
- **Rotación**: Botón para rotar la imagen en incrementos de 90°
- **Reiniciar**: Botón para volver a los valores originales

### 🖥️ **Pantalla Completa**
- **Modo inmersivo**: Visualización sin distracciones
- **Controles automáticos**: Se ocultan después de 3 segundos
- **Activación**: Botón de pantalla completa o tecla "F"

### ⌨️ **Atajos de Teclado**
- **F**: Alternar pantalla completa
- **Esc**: Cerrar visor o salir de pantalla completa
- **+/-**: Zoom in/out
- **0**: Reiniciar vista
- **R**: Rotar imagen
- **I**: Mostrar/ocultar información
- **←/→**: Navegar entre imágenes

### 📱 **Soporte Móvil**
- **Gestos táctiles**: Pellizco para zoom, toque para mostrar controles
- **Interfaz adaptiva**: Controles optimizados para pantallas táctiles
- **Navegación táctil**: Botones grandes para fácil navegación

### 📊 **Panel de Información**
- **Dimensiones**: Ancho x Alto en píxeles
- **Formato**: Tipo de archivo (JPG, PNG, etc.)
- **Tamaño**: Tamaño del archivo
- **Fecha de subida**: Cuándo se subió la imagen
- **Estado actual**: Zoom y rotación actuales

## 🔄 **Alternancia de Visores**

### Visor Simple
- Visualización básica y rápida
- Navegación con flechas
- Ideal para revisión rápida

### Visor Avanzado (Recomendado)
- Todas las características mencionadas arriba
- Experiencia inmersiva
- Ideal para análisis detallado de artwork

## 🚀 **Consejos de Uso**

1. **Para arte detallado**: Usa el visor avanzado con zoom para ver detalles
2. **Para navegación rápida**: El visor simple es más directo
3. **En móviles**: El visor avanzado se adapta automáticamente
4. **Para presentaciones**: Usa modo pantalla completa
5. **Para comparaciones**: Ajusta brillo/contraste según necesites

## 🎨 **Flujo de Trabajo Recomendado**

1. **Vista general**: Comienza en modo "Ajustar"
2. **Análisis**: Cambia a modo "Actual" y usa zoom
3. **Detalles**: Arrastra para navegar por la imagen ampliada
4. **Ajustes**: Modifica brillo/contraste si es necesario
5. **Navegación**: Usa flechas del teclado para cambiar imágenes
6. **Presentación**: Activa pantalla completa para una vista inmersiva

¡Disfruta de la nueva experiencia de visualización mejorada! 🎉
